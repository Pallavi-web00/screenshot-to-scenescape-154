# Brand source files

Original artwork supplied by DevOps Manager LLP. These files are the source of truth for the logo and
must never be redrawn, regenerated, recoloured or recompressed.

- `original/devops-manager-llp-infinity-logo.png` — the infinity logo exactly as supplied (766x310, unchanged).
- The header/footer logo (`src/assets/devops-manager-logo.png`, 492x160) is the "M DevOps Manager" mark
  cropped and scaled from the supplied brand sheet (`of2nd.pdf`) with its white background made
  transparent; the artwork itself is unchanged (matches the sheet to within 1% per pixel on average).

These files are not served to visitors from this folder; the site imports its logo from `src/assets/`.
